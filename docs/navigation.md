# 뒤로가기 · 화면 이동 규칙

앱 안 기록 스택(`src/lib/nav/history.ts`)과 `useLeave` 가 뒤로가기를 정한다 — 앱 안에서 왔으면 `history.back`, 바로 열었거나 외부를 거쳐 왔으면 상위 화면으로 replace.

## 규칙
- 저장 · 동의 · 해제처럼 **같은 자리로 돌아오는 서버 처리**는 `redirect(…, RedirectType.replace)` — 기록에 폼을 남기지 않는다
- **외부 페이지를 거쳐 도착**(소셜 로그인 · 계정 연결 콜백)하면 주소에 `from=auth` 를 붙이고, `NavTracker` 가 그 화면부터 기록을 새로 시작한 뒤 표시를 지운다
- 다음 화면에서 뒤로 돌아오는 게 자연스러운 이동만 push (검색 결과 → 장소, 받은 요청 수락 → 평가)

## 점검표 (2026-11-22)
| 흐름 | 도착 | 뒤로를 누르면 | 처리 |
|---|---|---|---|
| 로그인 (카카오 · Google · 네이버) | 홈 또는 닉네임 정하기 | 시작 화면이 아니라 상위 화면 | 콜백 `from=auth` |
| 계정 연결 | 설정 › 계정 | MY (외부 로그인 화면 아님) | 콜백 `from=auth` |
| 계정 연결 해제 | 설정 › 계정 | 이전 화면 (같은 화면 두 번 아님) | replace |
| 닉네임 정하기 · 약관 동의 | 원래 가려던 화면 | 폼으로 돌아가지 않음 | replace |
| 탈퇴 | 시작 화면 | 설정으로 돌아가지 않음 | replace |
| 평가 저장 | 들어온 화면 | — | `useLeave` (저장 후 이동) |
| 약속 만들기 · 링크 참여 · 끝내기 · 방문 기록 | 약속 화면 · 목록 · 다녀온 곳 | 폼으로 돌아가지 않음 | replace |
| 받은 함께 방문 요청 수락 | 평가 화면 | 받은 요청 | push (의도) |
| 검색 결과 열기 | 장소 상세 | 검색 | push (의도) |
