# coding/react.md — React (Vite SPA) 코딩 지침

> `_common.md` 를 먼저 읽고, **React 를 쓰는 화면**에 추가로 본 파일을 적용. 기준 스택은 **Vite + React**.
> 프로젝트에 프론트가 없으면 이 파일은 무시.

## 버전 / 도구
- Vite + React 함수형 컴포넌트 + Hook. 린트 `eslint`(react · react-hooks).
- **TypeScript 는 강제하지 않는다.** 쓰기로 정한 프로젝트만 쓴다 — 코드가 안 따르는 규칙을
  앞세우면 규칙 전체가 무시된다.
- 운영 빌드에 `console.log` 잔존 금지. 토큰·PII 콘솔 출력 금지.

## 구조
- 폴더: `components/`(ui·layout·feature) · `hooks/` · `stores/` · `lib/` · `pages/`.
- 비즈니스 로직은 컴포넌트에서 분리 → custom hook 또는 `lib/`. 컴포넌트는 렌더링에 집중.
- 전역 상태는 단일 store(zustand 등) + slice 분리. **서버 상태를 전역에 복사하지 않는다** —
  두 벌이 되면 어느 쪽이 참인지 화면마다 갈린다.

## 레이아웃 — 가정하지 말고 잰다
- **폭·높이를 가정하지 않는다.** 만들기 전에 실물을 계측한다(헤드리스 계측 하네스).
  안을 다 만든 뒤에 *그 칸에 안 들어간다* 를 알게 되는 것이 가장 비싸다.
- **넘침은 "잘림"으로 나타난다.** 스크롤 막대가 안 생기면 잘린 줄 알 방법이 없다 —
  눌리는 축에 `min-width`/`min-height` 와 **바닥값**을 둔다.
- flex 컨테이너 안에서 말줄임(`ellipsis`)은 `min-width: 0` 없이는 발동하지 않는다.
- 화면 밖으로 밀린 요소는 **없는 것과 같다** — 특히 돈이 드는 버튼. 좁은 폭에서 한 번 확인한다.

## 스타일링
- **색·간격·글꼴은 토큰 한 층에서.** 그 층이 곧 교체 지점이다 — 컴포넌트에 값을 흩지 않는다.
- **정적 자산(웹폰트 포함)은 자체 서빙.** CDN 링크는 인터넷이 막힌 기기에서 **조용히 시스템
  얼굴로 폴백**한다.

## 상태와 새로고침
- 화면 상태는 **"새로고침에 살아남아야 하는가"를 먼저 정한다.** 사용자가 한 선택(필터·검수 제외·
  이미 고른 결정)이 사라지면 **같은 일을 두 번 하고 돈도 두 번 쓴다**.
- 목록으로 되돌아왔을 때 낡은 값을 보이지 않게 재진입 시 다시 읽는다.

## 이벤트 / 재렌더
- 재렌더로 DOM 에서 떨어진 노드를 붙잡지 않는다(`closest`·ref 실패). 대상은 **식별자로** 찾는다.
- 성공이 실행 자리를 없애는 구조를 주의한다 — 결과 문구를 사라지는 자리에 두면 누른 사람이
  확인을 못 받는다.
- 라우팅 되부름은 플래그로 막지 말고 **상태로** 정리한다.

## 빌드 체인 없는 화면
- 프레임워크 없이 브라우저가 바로 읽는 HTML·CSS 는 `html-css.md` 를 따른다.
  한 저장소가 둘을 함께 쓰면 두 파일을 함께 읽는다.
