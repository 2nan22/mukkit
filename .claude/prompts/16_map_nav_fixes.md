## 1. 세션 목표 (성공 기준)
- 필터를 바꿔도 지금 보고 있는 지도 범위 · 배율이 유지된다. 남은 핀이 화면 밖에만 있을 때만 부드럽게 옮긴다
- 목록 시트를 손가락으로 끌어 올리고 내릴 수 있다 — 접힘 · 중간 · 펼침 세 단계에 맞춰 멈춘다
- '내 위치'를 누르면 내 위치 점과 정확도 원이 지도에 보이고, 지도 탭에 있는 동안 따라 움직인다
- 계정 연결 · 로그인처럼 외부 페이지를 거친 뒤 뒤로가기를 눌러도 외부 로그인 화면이 다시 뜨지 않는다. 앱 전체의 뒤로가기 흐름을 표로 점검해 어긋난 곳을 고친다

## 2. 원인 (조사 완료 · 2026-11-22)
- 배율: `src/features/map/PlaceMap.tsx:169-186` — `pins` 가 바뀔 때마다 `setBounds` 로 모든 핀에 맞춤(애니메이션 없음, 한 곳이면 `SINGLE_LEVEL` 로 확대). 처음 맞춘 초점(`MapView.tsx:43` 의 focus)도 버려짐
- 시트: `src/features/map/MapView.tsx:153-186` — 손잡이는 장식 span, 열고 닫기는 버튼 하나뿐. 끌기 코드 · `touch-action` 없음
- 내 위치: `MapView.tsx:45-56` 의 `goHere` 가 중심만 옮김 · `coords.accuracy` 미사용 · 내 위치 오버레이 없음 (`PlaceMap.tsx:145-156` 은 장소 핀만)
- 뒤로가기: 연결은 일반 `<a href="/auth/link/…">`(`settings/accounts/page.tsx:88`) → 외부 OAuth → `auth/callback` 이 `/settings/accounts` 로 리다이렉트. 브라우저 기록에 외부 페이지가 남는데, `useLeave`(`src/lib/nav/useLeave.ts:9`)는 앱 안 기록 스택(`history.ts:20-30`, 경로만 기록)이 2개 이상이면 `router.back()` → 외부 로그인 화면으로 돌아감

## 3. 추상화 전략
- 지도: "처음 한 번 맞추기"와 "필터로 핀만 바꾸기"를 나눈다 — `fitOnce` 플래그 또는 `fitKey` prop. 핀 오버레이 재생성은 선택 핀이 바뀔 때 전체를 다시 만들지 않게(`PlaceMap.tsx:132-157` 의존성 정리)
- 시트: 지도 탭 전용 `BottomSheet` 하나 — pointer 이벤트 + 스냅 높이 3개, 손잡이에만 `touch-action: none`, 목록 스크롤과 충돌하지 않게 목록이 맨 위일 때만 시트가 끌림
- 내 위치: `PlaceMap` 에 `me?: { lat; lng; accuracy }` prop → 점 · 원 오버레이. 위치는 `watchPosition`, 지도 탭을 떠나면 해제
- 뒤로가기: 외부를 거쳐 돌아온 도착점(콜백 리다이렉트)은 앱 기록 스택을 '여기서 새로 시작'으로 표시(예: `?from=auth` 를 NavTracker 가 보고 스택 초기화 후 주소에서 제거) → `useLeave` 가 back 대신 상위 화면 replace

## 4. 진행 현황
```
### 1. 필터 바꿀 때 배율 유지 · 필요할 때만 부드럽게 이동 · 핀 재생성 줄이기 → 검증: 필터 5번 바꿔도 배율 동일(캡처 비교), 선택 시 오버레이 재생성 0
### 2. 목록 시트 끌기 · 3단 스냅 · 목록 스크롤 충돌 없음 → 검증: 모바일 폭 E2E 로 드래그 · 스냅 확인
### 3. 내 위치 점 · 정확도 원 · 따라가기 · 권한 거부 안내 → 검증: 위치 흉내(geolocation override)로 점 표시 캡처
### 4. 뒤로가기 점검표 작성(화면별 도착 · 뒤로 기대 동작) · 외부 경유 도착점 처리 · 어긋난 곳 수정 → 검증: 계정 연결 → 뒤로 = 앱 화면, 로그인 · 가져오기 · 약속 링크 진입 각각 E2E
```
