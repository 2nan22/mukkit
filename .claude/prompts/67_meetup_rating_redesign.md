# 67_meetup_rating_redesign — 약속 잡기 단계형 · 평가 화면 정리 (시안 먼저)

## 0. 진입 전 필수
- `.claude/rules/`: `coding/_common.md` · `nextjs.md` · `react.md`
- 디자인 시안 아티팩트의 약속 · 평가 아트보드 · 디자인팀(에이전트) 검토

## 1. 세션 목표 (성공 기준)
- 새 약속: 한 화면 긴 폼 → 단계(무엇 · 언제 · 누구 · 어디서)마다 한 화면, 진행 막대 · 다음 · 뒤로
- 평가: 한 화면에 모든 요소 → 등급 먼저, 나머지(한 줄 평 · 사진 · 메뉴 · 함께 간 사람 · 공개 범위)는 접기 또는 단계
- 등급 칩 줄 맞춤: 5 + 1 처럼 한 줄 남는 배치 없애기(3 + 3 · 한 줄 가로 넘기기 등)
- 시안 2~3안 비교 → 사용자 선택 후 구현

## 3. 진행 현황
```
### 1. 시안(현재 · A · B) 아티팩트 → 사용자 선택
### 2. 약속 단계형 구현 → 검증: 단계 이동 · 뒤로 · 새로 고침에도 입력 유지
### 3. 평가 화면 정리 · 칩 배치 → 검증: 360px 캡처
```
