## 1. 세션 목표 (성공 기준)
- 새 약속: 한 화면에서 질문이 차례로(어떤 약속이에요? → 언제 만나요? → 이대로 만들까요?), 답하면 위로 한 줄 요약으로 접힘 · 바꾸기
    - 목적 아이콘 5칸 한 줄('모임'으로 줄임) · 날짜 4칸 · 시간대 점심 · 저녁 · 늦은 밤 3칸 + 시각 바꾸기
    - 기본값: 오늘 저녁이 남았으면 오늘 저녁, 아니면 내일 저녁 · 지난 날짜 · 시간대는 흐리게
- 만든 뒤 초대 화면(/meet/[id]/invite): 약속을 만들었어요 · 팔로우 줄마다 '초대' · 큰 버튼 '카카오톡으로 초대하기'(카카오 공유, 안 되면 공유 창 · 복사) · 링크 복사 · 나중에 할게요
- 약속 화면: 사람마다 상태(나 · 출발지 넣음 / 수락 기다리는 중 / 출발지 전) · '내 출발지 넣기' 카드 · '친구 더 초대하기'
- 받은 초대 버튼 '못 가요' · '참여하기'

## 3. 진행 현황
```
### 1. 새 약속 쌓이는 질문 화면 → 검증: 단위 시험(기본값 · 시간대) · 캡처
### 2. 만든 뒤 초대 화면 · 카카오 공유 → 검증: 캡처 · 공유 실패 시 복사
### 3. 약속 화면 상태 · 출발지 카드 · 받은 초대 문구 → 검증: 캡처
### 4. 에이전트 검토 · 검토 아티팩트
```
