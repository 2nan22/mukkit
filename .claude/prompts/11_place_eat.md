# 11_place_eat — 장소 상세 · 여기서 뭐 먹지

## 0. 진입 전 필수
- `scripts/sync-context.sh` · 규칙 파일 · 시안 `4 · 장소 상세` 를 먼저 연다
- `git checkout dev && git pull && git checkout -b feat/11_place_eat`
- 꼭지마다 묻지 않고 커밋 · push, 트레일러 없음 · 세션 끝에 화면 캡처 아티팩트 갱신

## 1. 세션 목표 (성공 기준)
- 장소 상세 /p/[place]: 지도 · 업종 · 주소 · 길찾기 · 네이버 / 카카오 원문 · 내 평가 · 팔로잉(과 공개) 평가 · 리스트에 저장 · 평가 수정, 저장 안 한 곳은 가고 싶은 곳으로 저장
- 여기서 뭐 먹지 /eat: 지금 위치 또는 지역 + 반경 → 업종별로 묶은 추천, 가게마다 추천 이유
    - 후보: 내 가고 싶은 곳 · 내 2 · 3스타 · 팔로잉의 2 · 3스타 · 취향 비슷한 사람의 공개 2 · 3스타
    - 제외: 내 추천 안 함 · 1스타 · 폐업 · 협찬 평가
    - 점수: 평가한 사람과 나의 비슷함 · 팔로우 여부 · 내 업종 취향 · 거리 — 가게 평균 점수는 만들지 않는다
- 지도 카드 · 피드 · 리스트에서 가게를 누르면 장소 상세로

## 2. 추상화 전략
- 후보 읽기는 security definer 함수 하나(볼 수 있는 평가 · 평가자와 나의 비슷함까지), 점수는 순수 함수(`scoreCandidates`)로 — 비중을 바꿔도 함수 하나만
- 장소 상세의 남 평가도 함수 하나(place_ratings)

## 3. 진행 현황
```
### 1. 장소 상세 · place_ratings · 가고 싶은 곳으로 저장 · 리스트에 저장
### 2. 추천 후보 함수 · 점수 계산 · 검사
### 3. 여기서 뭐 먹지 화면 · 진입점(홈 · 지도)
### 4. 가게 링크를 장소 상세로 · 캡처 아티팩트
```
