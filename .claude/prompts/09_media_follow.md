## 1. 세션 목표 (성공 기준)
- 평가에 내가 찍은 사진 · 짧은 영상을 올리고 지운다 (용량 · 개수 제한, 위치 정보 등 메타데이터 제거)
- 평가마다 공개 / 팔로워만 / 나만 — 메모는 언제나 나만
- 사람을 팔로우하고, 홈에 팔로우한 사람의 공개 평가가 피드로 (사진 · 등급 · 한 줄)
- 남의 비공개 사진 · 평가는 Storage 정책 · RLS 로 막힘 (검사로 확인)
- 장소 사진은 사용자가 올린 것만 — 플랫폼 사진은 쓰지 않는다

## 2. 추상화 전략
- 미디어는 `rating_media` 표 + Storage 버킷 하나, 경로에 사용자 id — 정책은 경로 첫 마디로
- 피드 읽기는 security definer 함수 하나(공개 범위 · 팔로우 판정) — 화면은 칸을 고르지 않는다

## 3. 진행 현황 (세션이 크면 사진 · 영상 / 팔로우 · 피드로 나눈다)
```
### 1. 평가 공개 범위 · rating_media · Storage 정책 · 검사
### 2. 평가 화면에 사진 · 영상 올리기 · 지우기
### 3. 팔로우 · 다른 사람 프로필
### 4. 홈 피드 (팔로우한 사람의 공개 평가)
```
