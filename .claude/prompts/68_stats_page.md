# 68_stats_page — 저장 기록 통계 화면

## 1. 세션 목표 (성공 기준)
- 내 정보 › '내 기록 통계': 저장 · 평가 수 추이(월별) · 등급 비율 · 업종 · 세부 업종 상위 · 자주 가는 동네(구) · 평가 남긴 비율
- 가게 평균 점수는 만들지 않는다(비협상 목표 2) — 내 기록만, 나만 봄
- 시안 먼저(67 시안과 함께 보여 줌) · 집계는 DB 함수 하나(security invoker, 내 행만)

## 3. 진행 현황
```
### 1. 시안 · 지표 확정 → 사용자 선택
### 2. 집계 함수 · 시험
### 3. 화면 → 검증: 큰 데이터(qa-seed 1150곳) 캡처 · 시간
```
