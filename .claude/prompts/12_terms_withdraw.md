# 12_terms_withdraw — 약관 · 개인정보 처리방침 · 탈퇴

## 0. 진입 전 필수
- 규칙 파일 · `git checkout dev && git checkout -b feat/12_terms_withdraw`

## 1. 세션 목표 (성공 기준)
- `/terms` · `/privacy` 공개 화면 (로그인 없이), 시작 화면 · 계정 화면에서 링크
- 처음 로그인 때 동의 체크(필수) → `profiles.terms_agreed_at` · `terms_version` 기록, 이미 가입한 사람은 홈 진입 시 동의 화면
- 계정 화면 '탈퇴' → 확인 후 사진 파일 삭제 → 계정 삭제(연쇄로 평가 · 메모 · 리스트 · 팔로우 · 가져온 원본 삭제) → 시작 화면
- pgTAP: 탈퇴 함수가 본인만 지우고 남의 데이터는 그대로

## 2. 추상화 전략
- 문서 버전 상수 `TERMS_VERSION` — 바뀌면 다시 동의 받기
- 계정 삭제는 security definer 함수 `delete_my_account()` 하나 — 서비스 키 불필요
- Storage 는 보호 트리거로 SQL 삭제 불가 → 서버 작업에서 사용자 세션으로 `rating_media.path` 목록 삭제 후 함수 호출

## 3. 진행 현황
```
### 1. 마이그레이션 (동의 칸 · 삭제 함수) · pgTAP
### 2. 약관 · 처리방침 화면
### 3. 동의 받기 (닉네임 화면 · 기존 사용자 동의 화면)
### 4. 탈퇴 흐름 · 캡처 아티팩트
```
