# 75 길찾기 앱 고르기 · 사진 크게 보기 · 팔로우 취소 확인

> 먼저 읽기: `.claude/vault/rules/coding/_common.md` · `nextjs.md` · `react.md` · `testing.md`

## 배경 (사용자 피드백 2026-11-26, 72 ~ 74 검토 뒤)
- 길찾기가 카카오맵으로 고정 — 카카오 · 네이버 · 구글 중 고를 수 있어야
- 평가 사진을 눌러 크게 보고 싶음
- '팔로잉' 버튼을 누르면 확인 없이 바로 팔로우가 끊김 (09 부터 그대로, 74 디자인 검토에서도 이 동작은 안 봄)

## 성공 기준
- 길찾기를 누르면 '어떤 앱으로 길찾기 할까요?' 시트 — 카카오맵 · 네이버 지도 · 구글 지도, 마지막으로 고른 앱을 맨 위(기기에 기억)
    - 각 앱 길찾기 주소(도착지 좌표 · 이름, 출발지 현재 위치) · 앱 없으면 웹 길찾기 · 컴퓨터는 웹
- 평가 사진을 누르면 화면 가득 검은 바탕에 크게 — 옆으로 넘기기 · 몇 번째인지 · 닫기 · 뒤로가기로 닫힘 · 두 손가락 확대
- '팔로잉'을 누르면 시트로 '○○님 팔로우를 취소할까요?' 확인 뒤 취소 (인스타그램 · 스레드 형식), 팔로우는 바로
- 디자인팀 · 코드 검토, 390px 캡처

## 꼭지
1. 길찾기 앱 고르기 → 검증: 주소 단위 시험 · 시트 캡처
2. 사진 크게 보기 → 검증: 누르기 · 넘기기 · 닫기 캡처
3. 팔로우 취소 확인 → 검증: 시트 캡처 · 취소 뒤 버튼
4. 검토 · 아티팩트 · dev 머지

## 범위 밖
- 영상 크게 보기(지금도 재생 컨트롤 있음) · 사진 저장 · 티맵 등 다른 앱
