## 1. 세션 목표 (성공 기준)
- 새벽 원본 새로 고침: 전날 저녁에 가져온 리스트도 다음 새벽에 다시 읽힘 · 로그인 유지 사용자도 대상
    - 확인: 운영 job_runs 기록상 크론은 매일 돌았음(03:36 폐업 확인 · 04:03 새로 고침). 새로 고침 0건은 '20시간 안에 읽은 리스트 제외' 조건 때문
    - 대상 조건 '마지막 로그인 30일' 은 자동 로그인(토큰 갱신)이면 안 바뀜 → 세션 갱신 시각 기준으로
- 실행 화면 · 페이지 이동 로딩이 화면 내용이 그려지기 전에 사라지지 않음
- 홈 내 지도: 지도에 보이는 동네 이름(구 · 동) 한 줄 · 아래 숫자(저장 · 3숟가락 · 가고 싶은 곳)는 보이는 지도 범위 기준
- 지도에서 가게를 고른 카드: 위로 끌면 장소 상세 · 아래로 끌면 닫기
- 버전 표기: 설정 맨 아래 '버전 YY.M.D (빌드 커밋)' — CalVer, 정식 앱 심사 번호는 출시 준비 때

## 2. 추상화 전략
- 동네 이름은 카카오 JS SDK services.Geocoder.coord2RegionCode(지도 SDK 에 이미 있음) — 새 키 없음
- 홈 숫자는 내 장소 전체 점(id · 좌표 · 등급, fetchAll)을 받아 지도 범위로 셈 — 서버 집계 함수 추가 없음
- 카드 끌기는 MapView 의 시트 끌기와 같은 방식(pointer · 임계값) — 상세는 기존 /p/[placeId] 로 이동

## 3. 진행 현황 (꼭지 = 커밋 단위)
```
### 1. 새로 고침 대상 조건(시간 · 세션 기준) 마이그레이션 → 검증: 로컬 DB 시험 · 운영 반영 뒤 due 쿼리
### 2. 실행 화면 · 이동 로딩을 화면 준비까지 유지 → 검증: 느린 네트워크 흉내 캡처
### 3. 홈 내 지도 동네 이름 · 보이는 범위 숫자 → 검증: 단위 시험(범위 셈) · 캡처
### 4. 지도 가게 카드 끌어 올려 상세 · 내려 닫기 → 검증: 브라우저에서 끌기
### 5. 버전 표기 → 검증: 설정 화면 캡처
```
