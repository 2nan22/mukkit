# 68-9 피드에 내 평가 · 평가 날짜를 지도 저장일로 · 가져온 메모 아이콘

> 먼저 읽기: `.claude/vault/rules/coding/_common.md` · `nextjs.md` · `react.md` · `testing.md` · `git_workflow.md`

## 배경 (사용자 피드백 2026-11-25)
1. 피드에 내 평가가 안 보임 — `feed()` 가 follows 조인만 해서 내 평가는 빠짐
2. 피드 날짜가 전부 같은 날 — 68 전에 가져온 688곳은 updated_at 이 가져온 때(11-21 17:22 ~ 17:23 한꺼번에)
    - 지도에 저장한 날은 user_places.saved_at 에 이미 있음(2018-12 ~ 2026-11). 68 이후 가져오기는 updated_at = 저장일로 넣고 있음
3. 장소 › 내 평가 메모 — 지도 앱에서 가져온 메모면 그 앱 로고가 보여야 함
    - 운영 확인: 메모 555개 모두 note_source 잡힘. 앞서 보낸 캡처는 시험하려고 메모를 고친 곳이라 메모 아이콘이었음 → 확인 · 설명만

## 성공 기준
- 피드 탭에 내 평가(전체 · 팔로워 공개)가 팔로잉 평가와 섞여 날짜순으로 보임. 홈 '팔로잉 새 평가'에는 내 것이 안 나옴
- 운영에서 한꺼번에 가져온 평가(같은 사람 · 같은 분에 10곳 넘게, 그 뒤 고치지 않은 것)의 updated_at 이 saved_at 으로 — 피드 날짜가 지도 저장일
- 올해가 아닌 날짜는 연도까지('2024년 3월 4일')
- 가져온 메모 로고: 로컬에서 고치지 않은 가져온 메모로 장소 › 내 평가 캡처

## 꼭지
1. feed(p_before, p_limit, p_mine default false) — p_mine 이면 내 평가(공개 · 팔로워)도. 피드 탭만 true → 검증: pgTAP(내 것 포함 · 나만은 빠짐 · 기본값은 빠짐)
2. 한꺼번에 가져온 평가 updated_at = saved_at 되돌리기 마이그레이션 → 검증: 운영 분포 조회 전후 · 로컬 시험
3. 카드 날짜 연도 표시 · 피드 빈 화면 문구 그대로 → 검증: 화면 시험 · 캡처
4. 가져온 메모 로고 캡처로 확인
