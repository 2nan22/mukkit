# 67-2_rating_steps — 평가 두 단계 (시안 2판 · 평가 쪽)

## 1. 세션 목표 (성공 기준)
- ① 어땠어요? 등급 넷 — 누르면 바로 ② · '아직 안 가 봤어요 › 가고 싶은 곳으로' · 나중에 할게요
- ② 기록: 위 '3숟가락 바꾸기' 칩 · 안 써도 저장돼요 · 먹은 메뉴 → 사진 → 한 줄 평가 → 함께 간 사람 · 방문일 · 나만 보는 메모 한 줄씩 · 협찬(켜면 '이렇게 보여요' 미리보기) · 저장 위 '팔로워에게 보여요 · 바꾸기'(시트, 마지막 값 기억) · 저장 하나
- 이미 평가한 곳은 ②로 바로
- 3숟가락 비교: 같은 업종 먼저 · 고르기 어려워요 · 나중에 할게요(버튼)
- 장소 상세 내 평가 카드 ⋯ › 평가 수정 · 3숟가락 순위 다시 정하기 · 평가 삭제(무엇이 지워지는지 확인)

## 3. 진행 현황
```
### 1. 두 단계 평가 화면
### 2. 공개 범위 시트 · 협찬 미리보기
### 3. 비교 시트 · 평가 카드 메뉴
### 4. 에이전트 검토 · 검토 아티팩트
```
