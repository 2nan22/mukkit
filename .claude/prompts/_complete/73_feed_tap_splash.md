# 73 피드 카드 누르기 · 홈 화면 앱 실행 애니메이션

> 먼저 읽기: `.claude/vault/rules/coding/_common.md` · `nextjs.md` · `react.md` · `testing.md`

## 배경 (사용자 피드백 2026-11-26)
- 피드 카드에서 가게 이름만 눌림 — 빈 곳을 눌러도 이동하는 게 보통. 따로 정한 이유는 없음(09 에서 이름에만 링크를 단 것)
- 홈 화면 앱으로 열면 실행 애니메이션이 안 보이고 아이콘만 약 3초 뒤 바로 앱 — 웹으로는 나옴
    - 원인 추정: 안드로이드 홈 화면 앱은 페이지가 다 뜰 때까지 시스템 실행 화면(아이콘)이 덮음. 애니메이션은 문서를 읽자마자 시작해 2.3초 안에 끝나 그 아래에서 다 지나감

## 성공 기준
- 피드 · 프로필 · 댓글 화면 평가 카드: 버튼 · 링크 · 사진 · 영상이 아닌 곳을 누르면 장소 상세
    - 누를 때 옅은 눌림 표시 · 글을 길게 눌러 고르는 건 이동 안 함 · 키보드로는 가게 이름 링크 그대로
- 홈 화면 앱(standalone)에서는 애니메이션을 페이지가 다 뜬 뒤(load) 시작 — 시스템 실행 화면이 걷힌 뒤에 보이게
    - 웹(브라우저)은 지금 그대로 · 한 번 열 때 한 번 · 눌러서 넘기기 그대로
- 실기기 확인은 사용자(안드로이드 홈 화면 앱)

## 꼭지
1. 카드 누르기 → 검증: 화면에서 빈 곳 · 버튼 · 사진 눌러 보기
2. 홈 화면 앱 애니메이션 시작 시점 → 검증: display-mode standalone 흉내로 load 뒤 시작 확인
3. 검토 · 아티팩트 · dev 머지
