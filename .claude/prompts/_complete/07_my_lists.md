# 07_my_lists — 내가 만드는 리스트 (지역 · 테마)

## 0. 진입 전 필수
- `scripts/sync-context.sh` 실행 → 바뀐 파일이 있으면 먼저 읽는다
- 규칙: `.claude/vault/rules/coding/_common.md` · `nextjs.md` · `react.md` · `testing.md` · `git_workflow.md` · `logging.md`
- 시안: `3 · 리스트 탭` · `3-1 · 내 리스트` · `8 · 등급별 보기` · `9 · 리스트 공유` 아트보드
- `pnpm db:start` · `pnpm test:db` · `pnpm test:local-db` 통과 확인. **`pnpm db:reset` 은 사용자에게 먼저 묻는다**
- `git checkout dev && git pull && git checkout -b feat/07_my_lists`
- 꼭지마다 묻지 않고 커밋 · push, 트레일러 없음, `gh` 미사용 · 세션 끝에 화면 캡처 아티팩트 갱신

## 1. 세션 목표 (성공 기준)
- 등급과 무관하게 저장한 장소로 리스트를 직접 만들고 · 이름 바꾸고 · 장소를 넣고 빼고 · 지운다
- 장소를 고를 때 가져온 원본(플랫폼 · 원래 리스트 이름 · 메모)으로 거르고 찾을 수 있다
    - 예: '난슐랭 3star' 에 있던 곳 중 '을지로' 메모가 있는 곳
- 리스트 탭에서 내 리스트 · 가져온 리스트를 본다, 리스트 지도 보기는 /map 재사용
- 공개 범위(비공개 · 링크 · 공개)만 정하고 공유 화면은 다음

## 2. 추상화 전략
- 리스트 쓰기는 `features/lists` 서버 함수 한 곳 (생성 · 이름 · 항목 추가/삭제 · 삭제) — RLS 로 본인만
- 장소 고르기 화면의 거르기는 imported_items 를 읽는 selector 하나 (출처 · 원래 리스트 · 메모 검색)

## 3. 진행 현황
```
### 1. ✓ 리스트 서버 함수 · 로컬 DB 검사 → 남의 리스트 수정 · 추가 · 삭제 불가
### 2. ✓ 리스트 탭 (등급별 · 내 리스트 · 가져온 원본) → 390px
### 3. ✓ 리스트 만들기 · 장소 고르기 → 난슐랭 2star + '여의도' 18곳으로 만들기
### 4. ✓ 리스트 상세 · 지도로 보기 · 공개 범위 → 공개 전환 · 빼기 17곳 · 리스트 지도
```
