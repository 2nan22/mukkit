# 76 구글 지도 저장 리스트 가져오기 (테이크아웃 파일)

> 먼저 읽기: `.claude/vault/rules/coding/_common.md` · `nextjs.md` · `react.md` · `testing.md`

## 배경 (사용자 요청 2026-11-27 '최대한 편하게, 복잡하지 않게')
- 구글 지도 공유 리스트를 읽는 공식 통로가 없음 — 구글이 공식으로 주는 내보내기(테이크아웃) 파일을 올려 가져온다
- 장소 · 출처 연결은 서버가 카카오에서 다시 확인한 것만 (32) — 구글 항목을 카카오 가게에 맞춰 저장

## 성공 기준
- 가져오기 화면에 '구글 지도' 줄 → /import/google
    - ① 테이크아웃 열기(받는 법 3단계) ② 받은 파일 올리기(zip 그대로 · csv · json 여러 개) ③ 찾은 리스트 보고 가져오기
- 파일은 기기에서 읽음 — 서버엔 리스트 이름과 가게 이름 · 메모 · 좌표 · 주소만
- 리스트마다: 구글 '가고 싶은 장소'는 가고 싶은 곳, 나머지는 같은 이름 먹킷 리스트(평가 전) — 고를 것 없이 기본값, 빼고 싶은 리스트만 끔
- 가게 맞추기: 좌표가 있으면 500m 안 같은 이름, 없으면 전국에서 같은 이름이 한 곳뿐일 때만 · 음식점 · 카페만
- 결과: 리스트마다 가져온 곳 · 못 찾은 곳(이름 목록, 검색으로 직접 추가 안내)
- 다시 올려도 늘지 않음(가져오기 규칙 그대로) · 메모는 구글 로고로(note_source google)
- 파일 읽기 · 이름 맞추기 단위 시험, 저장 DB 시험, 390px 캡처, 디자인 · 코드 검토

## 꼭지
1. 테이크아웃 파일 읽기(zip · csv · json → 리스트) + 시험
2. 카카오로 가게 맞추기 · 저장(서버 액션, 리스트 하나씩) + 시험
3. /import/google 화면 · 가져오기 화면 진입
4. 검토 · 아티팩트 · dev 머지

## 범위 밖
- 구글 공유 링크(maps.app.goo.gl) 붙여넣기 — 공식 통로 없음
- 못 찾은 곳 하나씩 고르기 화면(다음에) · 자동 새로 고침(파일이라 없음)
