# 33 — 이름 먹킷(임시) · 글자 로고 · 실행 화면

## 목표
- 화면 · 메타 · 약관의 '마이슐랭'을 '먹킷'으로 → 검증: grep 0건 · 화면 확인
- 홈 헤더 · 공유 화면 · 시작 화면에 수저 심볼 + 영문 대문자 MUKKIT 글자 로고 → 검증: 모바일 화면 캡처
- 안드로이드 실행 화면이 흰 바탕 위 사각 아이콘으로 보이지 않게 → manifest any 아이콘을 투명 바탕 심볼로

## 경위
- 홈 헤더가 촌스럽다는 의견 → 입체 아이콘 + 글자(거절) → 글자 로고 4방향 중 4번(영문 대문자 + 심볼) 선택
- 이름 후보 수십 개(에이전트 여러 관점 · GPT · Gemini)를 봤으나 마땅한 게 없어 '먹킷'으로 우선 결정, 떠오르면 다시 바꿈
