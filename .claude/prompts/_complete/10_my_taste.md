# 10_my_taste — MY 프로필 · 취향 겹침 추천

## 0. 진입 전 필수
- `scripts/sync-context.sh` · 규칙 파일 · 시안 `7 · MY` · `7-1 · 다른 사용자 프로필` · `1 · 홈`
- `git checkout dev && git pull && git checkout -b feat/10_my_taste`
- 꼭지마다 묻지 않고 커밋 · push, 트레일러 없음 · 세션 끝에 화면 캡처 아티팩트 갱신

## 1. 세션 목표 (성공 기준)
- MY: 닉네임 · 소개 · 팔로워 · 팔로잉 · 등급별 개수 · 내 리스트 · 프로필 수정, 설정(로그인 연결 · 로그아웃)은 따로
- 다른 사람 프로필: 소개 · 공개 평가 등급 분포 · 3스타 비율 · 협찬 평가 수 · 나와 겹치는 곳 · 리스트 / 평가 탭
- 취향 겹침: 같은 가게를 둘 다 평가했을 때 등급이 얼마나 비슷한지 — 볼 수 있는 평가만으로 계산
- 홈 · 사람 찾기에 '취향이 비슷한 사람' 추천 (팔로우 안 한 사람, 겹침 2곳 이상)
- 협찬 표시 평가는 비율 · 겹침 계산에서 뺀다 (비협상 목표 1)

## 2. 추상화 전략
- 겹침 계산은 security definer 함수 하나(taste_with · taste_matches) — 화면은 숫자만 받는다
- 등급 점수: 3스타 3 · 2스타 2 · 1스타 1 · 추천 안 함 0, 비슷함 = 1 − |차이| / 3 의 평균

## 3. 진행 현황
```
### 1. ✓ 취향 겹침 함수 · 프로필 통계 · pgTAP 7
### 2. ✓ MY 화면 · 프로필 수정 · 설정 분리
### 3. ✓ 다른 사람 프로필 보강 → 을지로미식가 겹침 11 · 비슷함 100%
### 4. ✓ 추천 사람 (홈 · 사람 찾기)
```
