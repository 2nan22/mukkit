# 38 — 리스트별 핀 색

## 목표
- 리스트마다 색이 있다(기본 색 자동 · 리스트 화면에서 10색 중 바꾸기) → 검증: DB 검사 · 화면
- 지도에서 '등급 · 리스트' 보기를 바꾼다. 리스트 보기에서는 핀을 리스트 색으로, 칩으로 리스트를 거른다 → 검증: 화면 캡처
- 리스트 보기에서도 1 · 2 · 3숟가락은 핀 안 숫자로 남긴다

## 추상화
- 색 이름 → 색값은 domain/listColor.ts 한 곳. DB 에는 이름만(null 이면 id 로 정한 기본 색)
- 한 장소가 여러 리스트에 있으면 가장 최근에 담은 리스트 색(고른 리스트가 있으면 그중)
