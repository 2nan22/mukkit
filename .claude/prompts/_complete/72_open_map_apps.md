# 72 지도 앱으로 열기 · 구글 지도

> 먼저 읽기: `.claude/vault/rules/coding/_common.md` · `nextjs.md` · `react.md` · `testing.md`

## 배경 (사용자 피드백 2026-11-26)
- 장소 상세 '길찾기' · '카카오' 버튼이 폰에서도 카카오맵 웹으로 열림 — 앱이 있으면 앱으로 가야 자연스러움
- '구글 맵 정보는?' — 네이버 · 카카오처럼 구글 지도로 볼 길이 없음
    - 해석: 구글 지도에서 열기 버튼. 구글 리뷰 · 사진 등 정보를 가져와 보여 주는 것은 하지 않음(장소 사진 · 리뷰 원칙, 구글 Places 는 유료 · 약관상 저장 제한)

## 성공 기준
- 폰(안드로이드 · 아이폰)에서 길찾기 · 카카오 · 네이버 버튼은 앱이 있으면 앱, 없으면 지금 웹 주소
    - 안드로이드는 intent:// (패키지 지정 · browser_fallback_url), 아이폰은 앱 주소(kakaomap:// · nmap://) 후 앱이 안 열리면 웹
    - 길찾기 도착지 = 가게 좌표 · 이름, 출발지 = 현재 위치(앱 기본), 수단은 앱 기본
- 컴퓨터에서는 지금처럼 웹 새 탭
- 장소 상세에 '구글' 버튼 — Google Maps URLs(api=1 검색, 이름 + 주소), 폰에선 구글 지도 앱이 알아서 받음
- 주소 만들기는 순수 함수 + 단위 시험(앱 주소 · 대체 웹 주소 · 이름 인코딩)

## 꼭지
1. 외부 지도 주소 함수(domain) + 시험 → 검증: 단위 시험
2. 버튼 연결(장소 상세 · 지도 가게 카드의 원문 링크 같은 곳 모두) → 검증: 컴퓨터 화면 캡처 · 폰 흉내(UA)로 만들어진 주소 확인
3. 검토 · 아티팩트 · dev 머지

## 범위 밖
- 구글 리뷰 · 사진 · 평점 가져오기 · 구글 장소 ID 저장
- 티맵 등 다른 길찾기 앱 고르기
