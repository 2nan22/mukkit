- 결정 기록: 브랜드 표기(주황 수저 심볼 + 한글 '먹킷' 크게 · 영문 MUKKIT 작게 두 줄, 44) · 앱 아이콘 입체 1안 · 실행 화면 흰 바탕 + 투명 심볼(manifest any)
- 디자인팀(에이전트) 검토 필수 · 문구는 상용 서비스 말 차용 · AI 같은 말 금지

## 1. 세션 목표 (성공 기준)
- 처음 들어올 때(홈 화면 앱 · 웹 첫 진입) 심볼이 짧게 움직이는 실행 애니메이션 — 800ms 이하, prefers-reduced-motion 이면 정지
    - iOS 홈 화면 앱은 시스템 스플래시(apple-touch-startup-image) → 앱 안 첫 화면으로 이어짐이 끊기지 않게
- BI/CI 세련되게: 글자 로고 간격 · 굵기 · 심볼 비율 · 색 체계(주황 · 잉크 · 3숟가락 빨강) 정리, 시안 2~3안 → 사용자 선택
- 바뀐 BI 를 앱 아이콘 · 실행 화면 · 시작 화면 · 공유 미리보기(OG)에 일관 적용

## 2. 추상화 전략
- 로고 · 심볼은 components/brand 한 곳(Wordmark · Symbol) — 화면은 가져다 쓰기만
- 실행 애니메이션은 CSS 만(JS 타이머 없이) · 첫 진입 한 번(sessionStorage 표시, 실패해도 화면은 정상)

## 3. 진행 현황 (꼭지 = 커밋 단위)
```
### 1. 디자인팀 BI 시안 2~3안 · 사용자 선택 → 검증: 시안 아티팩트
### 2. 심볼 · 글자 로고 교체 · 아이콘 · OG → 검증: 아이콘 크기별 캡처
### 3. 실행 애니메이션 · 스플래시 이어짐 → 검증: 실기기 홈 화면 앱 · 줄인 움직임
```
