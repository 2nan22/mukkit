## 0. 진입 전 필수
- `scripts/sync-context.sh` 실행 → 바뀐 파일이 있으면 먼저 읽는다
- 규칙: `.claude/vault/rules/coding/_common.md` · `nextjs.md` · `react.md` · `testing.md` · `git_workflow.md` · `logging.md`
- 시안: `9 · 리스트 공유` · `10 · 공유 받은 사람 (비로그인)` · 하단 메뉴(홈 · 지도 · 리스트 · MY)
- `git checkout dev && git pull && git checkout -b feat/08_share_shell`
- 꼭지마다 묻지 않고 커밋 · push, 트레일러 없음, `gh` 미사용 · 세션 끝에 화면 캡처 아티팩트 갱신

## 1. 세션 목표 (성공 기준)
- 링크 · 공개 리스트를 비로그인으로 열람 (/l/[id]) — 장소 · 등급만, 메모 · 원본은 절대 안 보임
- 카카오톡 공유 미리보기(OG 제목 · 설명 · 이미지)
- 링크 복사 · 공유 화면, 비공개 리스트 링크는 '볼 수 없는 리스트'
- 홈 · 지도 · 리스트 · MY 하단 메뉴로 화면 간 이동 통일

## 2. 추상화 전략
- 공개 열람 읽기는 anon 키 + RLS 만 믿는다 — 서버 함수가 메모 컬럼을 고르지 않는다
- 하단 메뉴는 로그인 화면 공통 레이아웃 하나

## 3. 진행 현황
```
### 1. 공개 리스트 열람 /l/[id] · RLS 검사 → 검증: 비로그인 · 비공개 · 메모 미노출
### 2. OG 미리보기 · 링크 복사 공유 화면 → 검증: 메타 태그
### 3. 하단 메뉴 레이아웃 → 검증: 390px 네 화면 이동
```
